## 📊 Gráficas Dinámicas de Personas a Cargo y Analítica

1. **Personas a Cargo por Líder (Gráfica de Barras Pastel):**
   - Muestra cuántos colaboradores, practicantes o alumnos tiene asignado cada coordinador o docente líder.
   - **Interactividad total:** Al hacer clic sobre cualquier barra del gráfico, se abre inmediatamente el Dashboard individual del líder correspondiente.
2. **Distribución del Staff por Departamento (Gráfica Donut Pastel):**
   - Visualiza el equilibrio entre Docentes (36%), Comunicaciones (36%), Traductores (21%) y Empleabilidad/Liderazgo (14%).
3. **Adopción de Herramientas de Inteligencia Artificial (Barras Horizontales):**
   - Nivel de uso activo de herramientas como ChatGPT-4o, Claude 3.5 Sonnet, DeepL Pro API, Whisper AI, Midjourney v6 y Make.com en las tareas cotidianas.

## 💻 Cómo Abrir y Usar Localmente

Puedes abrir directamente el archivo en cualquier navegador:

```bash
open /Users/melaniealmeyda/.gemini/antigravity/scratch/polyglot-staff-dashboard/index.html
```

O iniciar un servidor local rápido:

```bash
cd /Users/melaniealmeyda/.gemini/antigravity/scratch/polyglot-staff-dashboard
python3 -m http.server 8080
```
Y abrir en el navegador: `http://localhost:8080`
